DESK

PC のフォルダが、自分の「デスク」になる。Your PC folders become your own desk.

デスク画面では、フォルダの中の PDF・作業ファイル・画像が大きめのサムネイルで並びます。机の上に書類を広げるように好きな場所へ置いて、重ねれば結合、左のフォルダへドラッグすれば移動。JPEG や PNG も扱えるので、文書と写真や画像を1つの書類にまとめられます。

The desk shows a folder's PDFs, work files and images as large thumbnails. Spread them out like papers on a desk, drop one onto another to merge, drag to a folder on the left to move. JPEG and PNG work too, so you can combine documents with photos and images into a single file.

デスクでできることOn the desk

  • ダブルクリックで別ウインドウのエディターが開き、［PDF保存］で元の PDF をそのまま更新
  • 結合・ページごとにばらす・名前変更・印刷。間違えても［元に戻す］で何回でも戻せる
  • Box Drive などの共有フォルダにも対応（Edge / Chrome）
  • Preview any document page by page without opening it
  • Double-click to open the editor in its own window; [Save PDF] updates the original file
  • Merge, split, rename and print — and undo as many times as you like
  • Works with shared folders such as Box Drive (Edge / Chrome)

目玉機能Highlights

「それができると助かる」を、ちゃんと形に。The things you always wished a PDF tool could do.

COPY → EXCEL

選んだ範囲だけコピー。表はそのまま Excel へ。Copy just the area you pick — tables go straight into Excel.

ページ上を四角で囲んで Ctrl+C。囲んだ所の文字だけがコピーされ、表は Excel に貼るとセルごとにきちんと分かれます。必要な列だけ、必要な行だけも思いのまま。

Draw a box and press Ctrl+C. Only the text inside is copied, and tables split neatly into cells when pasted into Excel — even just the rows or columns you need.

こんな時にUse cases
  • 請求書・見積書の明細を、Excel の集計表へ転記
  • PDF でしか届かない価格表から、必要な品番の行だけ抜き出す
  • 報告書の数値を、メールや資料に貼り付け
  • Move invoice or quote line items into an Excel sheet
  • Pull only the rows you need from a PDF price list
  • Paste figures from a report into an email or slides

TWO-PAGE VIEW

2枚同時ビューで、見比べながら書き込む。Two pages at once — compare while you write.

サムネイルを Ctrl+クリックするだけで、2ページが横に並びます。どちらのページにも、そのまま書き込みや付箋・ハンコを入れられます。

Ctrl+click a second thumbnail and two pages sit side by side. Write, add notes and stamps on either page directly.

こんな時にUse cases
  • 見積書と仕様書、請求書と納品書を並べて照合
  • 修正前と修正後の版を見比べてチェック
  • 本文を見ながら、別紙の該当箇所に付箋で指示
  • Check a quote against its specs, an invoice against a delivery note
  • Compare the old and new versions of a document
  • Read the main text while leaving notes on the appendix
KEEP EDITING

編集したまま保存して、続きは明日でも、誰かでも。Save with edits intact — continue tomorrow, or let someone else.

「作業ファイル保存」すると、書き込みを編集できる状態のまま .frontpdf ファイルに残せます。開けばハンコも付箋も黒塗りも、動かしたり直したりできる状態で再開できます。

"Save work file" keeps everything editable in a .frontpdf file. Open it again and every stamp, note and black-out can still be moved or changed.

こんな時にUse cases
  • 付箋に指示を書いて同僚へ。相手は指示どおりに直して返すだけ
  • 大量の書類を、途中で保存して翌日に続きから
  • チェック担当と作成担当で、同じファイルを行き来
  • Leave instructions on notes for a colleague, who fixes and returns it
  • Save a big job halfway and continue the next day
  • Pass the same file back and forth between writer and checker

※ 作業ファイルには元の PDF がそのまま入ります。社外に渡すときは［PDF保存］で作った PDF を。

The work file contains the original PDF. Send a PDF made with [Save PDF] outside your organization.

RASTERIZE

塗ったページだけ画像化して、文字を残さない。Rasterize only the masked pages — no hidden text left.

普通の黒塗りは上に四角を重ねるだけで、下の文字はコピーできてしまいます。Front PDF は保存するときに注意を出し、黒塗りしたページだけを画像にして文字データを消せます。ほかのページは文字を選べるまま。

An ordinary black box only covers text — it can still be copied. Front PDF warns you when you save and turns only the masked pages into images, removing their text. Other pages stay searchable.

こんな時にUse cases
  • 個人情報や単価を黒塗りして、社外へ提出
  • 検索で見つけた電話番号を一括で黒塗り
  • 開示資料の一部だけを確実に隠す
  • Mask personal data or prices before sending outside
  • Black out every phone number found by search
  • Reliably hide just part of a disclosed document
PASTE IMAGES

スクショも画像も、Ctrl+V でそのまま貼る。Screenshots and images — just Ctrl+V.

Snipping Tool で切り取った画面やグラフを Ctrl+V。マウスのある場所に、画面で見たままの大きさで貼り付きます。画像ファイルはドラッグ＆ドロップでも。サムネイル側に貼れば新しいページになります。

Ctrl+V a screen capture or chart from Snipping Tool. It lands where your mouse is, at the size you saw on screen. Drag and drop image files too — drop on the thumbnails to add a new page.

こんな時にUse cases
  • システム画面のスクショを手順書に貼る
  • Excel のグラフを報告書の余白に追加
  • スマホで撮った写真を、書類の最後のページとして追加
  • Paste system screenshots into a how-to document
  • Add an Excel chart to the margin of a report
  • Append a phone photo as the last page

安全性Safety

会社や学校の PC でも、安心して使えるように。Made to be safe on company and school PCs.

無料Free

広告も課金もありません。MIT ライセンスで、会社・学校でも無料で使えます。

No ads, no payments. MIT-licensed and free for companies and schools.

外部と通信しないNo network access

PDF はブラウザの中だけで処理。アップロードも、アクセス解析も、自動更新の通信もありません。

PDFs are processed only in your browser. No uploads, no analytics, no update checks.

インストール不要No installation

exe ではなく HTML ファイル1つ。管理者権限も、PC の設定変更もいりません。

Not an exe — one HTML file. No admin rights, no changes to your system.

外部プログラムを動かさないNo external code

外部のスクリプトやプログラムを読み込んだり実行したりしません。必要な部品はすべて1ファイルに同梱。マクロもアドインもありません。

Loads and runs no external scripts or programs. Every component is inside the one file. No macros, no add-ins.

個人情報を扱わないNo personal data

アカウント登録なし。アクティベーションに使う ID も、アプリが作るランダムな番号で、PC や個人の情報は含みません。

No account. The activation ID is a random number generated by the app, with no PC or personal information.

本物か確かめられるVerifiable

公式版の SHA-256 を公開。このページの「本物チェック」で改ざんを見分けられます。

The official SHA-256 is published. "Verify" on this page detects modified copies.

中身を見られるOpen source

ソースコードはすべて GitHub で公開。情報システム部門でも中身を確認できます。

All source code is on GitHub, so IT departments can review it.

メールで配らないNever by email

作者はメールで配布しません。出どころのわからないファイルが出回らないよう、公式ページからだけ配っています。

The author never distributes by email — only from this official page.

※ 通信しないことは、ブラウザの開発者ツール（F12）のネットワーク欄でも確かめられます。You can confirm there is no network traffic in your browser's developer tools (F12) Network tab.

よくある質問FAQ

本当に無料ですか？会社で使ってもいいですか？Is it really free? Can I use it at work?

はい、無料です。MIT ライセンスなので、個人・会社・学校を問わず無料で使え、商用利用もできます。Windows・Mac の Edge / Chrome で動作を確認しています（Windows のタブレットを含みます）。Safari・Firefox、iPad・スマホでは動作を確認していません。会社でお使いになる場合は、ソフトの利用に関する社内の規程をご確認のうえご利用ください。詳しい仕様は GitHub のページでご確認いただけます。

Yes, it is free. Under the MIT License it can be used by individuals, companies and schools, including for commercial purposes. It is tested in Edge / Chrome on Windows and Mac (including Windows tablets); it is not tested in Safari or Firefox, or on iPad and smartphones. If you use it at work, please check your organization's software policy first. Full technical details are on the GitHub page.

開いた PDF が外部に送られることはありますか？Are my PDFs sent anywhere?

ありません。アプリは自分から通信しない作りで、PDF はブラウザの中だけで処理します。

No. The app makes no network requests by itself; PDFs are processed only in your browser.

なぜアクティベーションが必要なのですか？Why is activation needed?

メールなどで出どころのわからないファイルが出回るのを防ぎ、公式の最新版を使ってもらうためです。料金や個人情報の入力はありません。

To keep files of unknown origin from circulating and make sure everyone uses the latest official version. No payment and no personal information.

ID が変わった／もう一度登録画面が出たMy ID changed / the registration screen came back

ID はブラウザごとに作られます。ブラウザのデータ（サイトデータ）を消したときや、別のブラウザ・シークレットウィンドウで開いたときは、新しい ID になります。新しい ID でもう一度パスワードを発行してください。何度でも無料です。ダイアログは有効化するまで閉じないので、ID を見逃しても、アプリを開き直せば同じ ID が表示されます。

The ID is created per browser. Clearing site data, or opening the app in another browser or a private window, creates a new ID. Just issue a new password — free, any number of times. The dialog stays open until you activate, and reopening the app shows the same ID.

人に勧めたいときは？How do I recommend it?

ファイルを送らずに、このページの URL を教えてください。

Please share this page's URL instead of the file.

改変して配布してもいいですか？May I modify and redistribute it?

MIT ライセンスの範囲で自由です。ただし改変版は「Front PDF」以外の名前で配布してください。改変版によって生じた問題について作者は責任を負いません。

Yes, under the MIT License. Please use a name other than "Front PDF" for modified versions. The author is not responsible for problems caused by modified versions.

iPad やスマホで使えますか？Does it work on iPad or smartphones?

iPad・iPhone には対応していません（標準のアプリでは HTML ファイルを動かせないため）。Android・Chromebook は動作を確認していません。Windows のタブレット（Surface など）は、Edge / Chrome でパソコンと同じように使えますが、タッチ操作向けには作っていないため使いにくい場面があります。

iPad and iPhone are not supported (their standard apps cannot run an HTML file). Android and Chromebook are not tested. Windows tablets (such as Surface) work like a PC in Edge / Chrome, although the app is not designed for touch.

デスクはどのブラウザで使えますか？Which browsers support the desk?

Microsoft Edge と Google Chrome（Windows・Mac）です。Safari や Firefox にはフォルダを扱う仕組みがないため、デスクは使えません（エディターも動作は確認していません）。

Microsoft Edge and Google Chrome (Windows and Mac). Safari and Firefox cannot work with folders, so the desk is not available there (the editor is not tested in them either).

「_削除予定」フォルダは何ですか？What is the "_削除予定" folder?

デスクで削除した書類や、上書きする前の版を入れておくフォルダです（Windows や Mac のごみ箱ではありません）。必要になったときに、そのフォルダの中へ自動で作られます。中身はデスクの［元に戻す］で戻せます。不要になったら「_削除予定」フォルダを右クリックして［空にする］で完全に削除できます。

It holds documents you delete on the desk and the previous versions of overwritten files (it is not the Windows or Mac trash). It is created inside the folder only when needed. You can bring items back with [Undo] on the desk, and right-click the folder → [Empty] to delete them permanently.

できないことは？What can't it do?

既存の文字の直接書き換え、OCR、電子署名、フォーム作成、パスワード付き PDF の読み込みには対応していません。

Editing existing text in place, OCR, digital signatures, creating forms and opening password-protected PDFs are not supported.
