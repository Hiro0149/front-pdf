できることWhat it does

「ちょっと PDF をいじりたい」をこれ1つで。Everything for "I just need to tweak this PDF".

📑結合・分割・並べ替えMerge, split, reorder

PDF と画像をまとめて読み込み、ドラッグで並べ替え。回転・削除・白紙追加、範囲や N ページごとの分割書き出し。

Load PDFs and images, drag to reorder, rotate, delete, add blank pages, and export by ranges or every N pages.

✏️書き込みAnnotate

ペン・ブラシ・蛍光ペン・図形・表・矢印・文字・絵文字・画像。Snipping Tool の画像も Ctrl+V で貼れます。

Pen, brush, highlighter, shapes, tables, arrows, text, emoji and images. Paste screenshots with Ctrl+V.

🗒️付箋Sticky notes

DocuWorks のような貼り紙の付箋。PDF の注釈として書き出すので、相手の Acrobat や Edge でもそのまま読めます。

Paper-style notes, exported as PDF annotations that show up in Acrobat or Edge.

💮ハンコ帳Stamp book

日付印・丸印・角印・チェック・花まる・スキャンした印影。よく使うハンコはブラウザに記憶されます。

Date stamps, seals, check marks, "hanamaru" and scanned seals, remembered in your browser.

⬛黒塗り・白塗りBlack-out / white-out

塗ったページだけ画像化して書き出す「安全な書き出し」で、下の文字データを残しません。

"Safe export" rasterizes only the masked pages, so no text remains underneath.

🔍検索・表コピーSearch & table copy

文字検索と一括マーカー・一括黒塗り。範囲を囲んでコピーすると、表は Excel にそのまま貼れます。

Search with bulk highlight or black-out. Box-select text and tables paste straight into Excel.

💾作業ファイルWork files

書き込みを編集できる状態のまま保存（.pdfkobo）。付箋で指示して同僚に渡す使い方も。

Save your work with markups still editable (.pdfkobo) and hand it to a colleague.

🎨スキン・多言語Skins & languages

モダン・ダーク・レトロPC・アクア・ゲーム機の5スキン。日英中（簡・繁）葡仏韓の7言語。

Five skins and seven languages: Japanese, English, Chinese (Simplified/Traditional), Portuguese, French, Korean.

安心して使える3つの約束Three promises

会社や学校の PC でも使えるように作りました。Built to be usable on company and school PCs.

🔒 外部と通信しないNo network access

PDF はブラウザの中だけで処理します。アップロードもアクセス解析もありません。

PDFs are processed only inside your browser. No uploads, no analytics.

📄 インストール不要No installation

exe ではなく HTML ファイル1つ。管理者権限も不要で、PC の設定を変えません。

Not an exe — one HTML file. No admin rights, no changes to your PC.

🔎 中身を確認できるOpen and verifiable

MIT ライセンスのオープンソース。公式版かどうかは SHA-256 で誰でも確認できます。

Open source under MIT. Anyone can verify the official build with SHA-256.

よくある質問FAQ

本当に無料ですか？会社で使ってもいいですか？Is it really free? Can I use it at work?

はい。MIT ライセンスなので、個人・会社・学校を問わず無料で使えます。商用利用も可能です。

Yes. Under the MIT License it is free for individuals, companies and schools, including commercial use.

開いた PDF が外部に送られることはありますか？Are my PDFs sent anywhere?

ありません。アプリは自分から通信しない作りで、PDF はブラウザの中だけで処理します。ブラウザの開発者ツール（F12）のネットワーク欄でも確認できます。

No. The app makes no network requests by itself; PDFs are processed only in your browser. You can confirm this in the browser's developer tools (F12) Network tab.

なぜ利用登録が必要なのですか？Why is registration needed?

メールなどで出どころのわからないファイルが出回るのを防ぎ、必ず公式の最新版を使ってもらうためです。料金や個人情報の入力はありません。

To keep files of unknown origin from circulating by email and make sure everyone uses the latest official version. No payment and no personal information.

ID が変わった／もう一度登録画面が出たMy ID changed / the registration screen came back

ブラウザのデータ（サイトデータ）を消すと ID が新しくなります。お手数ですが、新しい ID でもう一度発行してください。何度でも無料です。

Clearing browser (site) data creates a new ID. Please issue a new registration text for it — it is free, any number of times.

人に勧めたいときは？How do I recommend it to others?

ファイルを送らずに、このページの URL を教えてください。いつでも改ざんされていない最新版を入手できます。

Please share this page's URL instead of the file, so they always get the latest unmodified version.

改変して配布してもいいですか？May I modify and redistribute it?

MIT ライセンスの範囲で自由です。ただし、利用者が混乱しないよう、改変版は「PDF_KOBO」以外の名前で配布してください。改変版によって生じた問題について作者は責任を負いません。

Yes, under the MIT License. To avoid confusion, please distribute modified versions under a name other than "PDF_KOBO". The author is not responsible for problems caused by modified versions.

できないことは？What can't it do?

既存の文字の直接書き換え、OCR、電子署名、フォーム作成、パスワード付き PDF の読み込みには対応していません。

Editing existing text in place, OCR, digital signatures, creating forms and opening password-protected PDFs are not supported.
