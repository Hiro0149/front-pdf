# Front PDF 使用说明书（简体中文）v1.0.2 (2026-11-22)

## 1. 概要
- Front PDF 是只需用浏览器（推荐 Edge / Chrome）打开一个 HTML 文件（约 3.7MB）即可使用的 PDF 编辑工具，无需安装。
- 完全离线。文件不会发送到外部，所有处理都在本机浏览器内完成。
- 功能：PDF/图片的合并、拆分、排序、旋转、删除；在页面上标注（笔、图形、文字、便签、印章、表情符号、图片）；涂黑/涂白；文字搜索；框选复制文字（表格可直接粘贴到 Excel）；水印；统一 A4；2合1/4合1；导出 PNG；工作文件。
- 也可以添加空白页，自由排版制作文档（类似文字处理软件）。

## 2. 画面构成
- 标题栏右侧：图片导入（打开 PNG/JPEG 时的排版：放在A4上／保持图片尺寸）、皮肤、语言（地球图标）、?（帮助）、ⓘ（版本与许可）。
- 工具栏第1行：文件（打开／保存工作）、视图（▦ 网格／✎ 编辑）、页面（添加空白页、左旋、右旋、复制、删除页面）、撤销／重做，最右侧为导出（导出PNG／导出PDF）。
- 工具栏第2行（仅编辑模式）：◀ 页码 ▶、缩放（－／菜单／＋）、搜索（输入框、▲▼、结果数、全部高亮、全部涂黑）、全部（水印、清除标注）。
- 左侧：缩略图（上方有"大小"滑块和"列数"），拖动分隔线可调整宽度。
- 中左为工具箱（按功能分5组），中央为页面查看器，右侧为属性面板，底部为状态栏。

## 3. 模式
- 编辑模式（✎ 编辑）：左侧缩略图，在右侧页面上直接标注。
- 网格模式（▦ 网格）：只显示大缩略图，用于整理页面。双击或按 Enter 进入该页编辑。
- 双页显示：点击一张缩略图，再按住 Ctrl 点击另一张，两页并排显示且都可标注（正在操作的页面有边框）。只点击一页即可恢复。

## 4. 打开与合并
- 用［打开］(Ctrl+O) 或拖放添加 PDF / PNG / JPEG / 工作文件(.frontpdf)，数量不限。缩略图顺序即合并顺序。
- 图片会转换为单页 PDF（按"图片导入"设置）。
- 无法打开带密码的 PDF。

## 5. 页面操作
- 选择：点击、Ctrl+点击（追加）、Shift+点击（范围）、在缩略图区按 Ctrl+A（全选）。
- 排序：拖动缩略图。
- 旋转（↺↻）、复制、删除页面（Delete）对所选页面执行。添加空白页会在当前页后插入 A4 空白页。
- 撤销 Ctrl+Z／重做 Ctrl+Y（页面操作与标注共用历史）。

## 6. 工具
- 选择：［选择］点击选择标注、拖动移动、拖四角缩放、方向键微调（Shift 为10倍）、Delete 删除；从空白处拖动可选择文字。［选字］只选择拖动框内的文字。
- 绘制：［笔］、［毛笔］（慢＝粗、快＝细，数位板支持压感，可切换为喷枪）、［荧光笔］、［橡皮擦］（笔迹只擦经过处，其他整体删除，不会擦除原 PDF）。笔类按 Shift 画45°直线，按 Ctrl 画任意角度直线。
- 图形：［矩形］［椭圆］［直线］［箭头］［星形］［表格］（在右侧面板设置行数、列数，只有边框）。按 Shift 画正方形／正圆／45°线。
- 填充·遮盖：［高亮］（半透明黄色带）、［涂白］、［涂黑］、［油漆桶］（点击标注＝改色；点击笔等围出的内侧＝填充）、［吸管］（拾取页面颜色并设置到上一个工具或所选标注，绘制时可 Alt+点击）。
- 插入：［文字］（点击放置，在右侧面板设置内容、大小、字体、颜色、背景）、［表情符号］（在面板中选择后点击放置，也可用 Win+.）、［便签］（纸条式，点击后直接输入，双击再次编辑）、［印章］（从右侧印章簿选择后点击盖章）、［图片］（选择文件放置）。
- 右侧面板按钮：删除／复制／置于顶层／置于底层／应用到所有页（在其他所有页面相同位置复制）／设为默认／加入印章簿。

## 7. 印章簿
- 类型：勾选（✓）、花丸（表扬用）、方框、双框、椭圆、圆章（1–3字竖排）、日期章（上栏・日期・下栏）、方章（4字两列，从右起）、图片（扫描印鉴）。
- 可编辑文字、颜色、大小、日期格式（2026.11.20 / ’26.11.20 / R8.11.20 等）；勾选"使用盖章当天日期"则每次自动为当天日期。
- ［从图片添加］可添加扫描的印鉴（白色自动变透明）。
- 自动保存在浏览器中（每台电脑、每个浏览器各自保存）。［导出（备份）］生成 StampBook_Front_PDF.json，［导入］读取。

## 8. 便签
- 类似 DocuWorks 的纸条式便签。颜色（黄、粉、浅蓝、绿、橙、紫、白）、字号、文字颜色、粗体、作者名（会被记住）。
- 导出 PDF 时成为"注释"：Acrobat 和 Edge 中按原样显示，接收者可移动或删除，并会出现在注释列表中。开启"烧录到页面"则成为正文的一部分。
- 2合1/4合1 导出时不包含便签。

## 9. 文字选择・复制・搜索
- ［选字］：只选择中心位于拖动框内的文字，也可只选表格的某几列。
- 复制格式：表格（制表符分隔，粘贴到 Excel 会分成单元格）／文本（空格分隔）。Ctrl+C 复制，Ctrl+A 全选本页。
- 搜索：Ctrl+F → 输入 → Enter（下一个）／Shift+Enter（上一个）。不区分全角半角与大小写。［全部高亮］［全部涂黑］可一次处理。
- 扫描的 PDF 没有文字数据，无法选择或搜索（不支持 OCR）。

## 10. 水印
- ［水印］为所有页面添加水印并选中。可在右侧面板修改文字、大小、角度、颜色、浓度，或［删除水印］。点击页面上的水印文字也可选择。

## 11. 粘贴与拖放图片
- 用截图工具等复制的图片按 Ctrl+V：鼠标在页面上时贴在该位置，否则贴在可见区域中央，大小与屏幕上看到的一致。鼠标在缩略图区时作为新页面添加。
- 将图片文件拖放到页面上＝贴在该位置；拖放到缩略图区＝新页面。
- Ctrl+V 粘贴文字时作为文字对象。

## 12. 导出
- ［导出PDF］：合并全部页面／仅所选页面／每页一个文件／每N页拆分／按范围拆分（例 1-3, 4-6, 7）。选项：统一为 A4、裁剪边距（mm）、2合1／4合1、文档标题。
- 使用了涂黑/涂白时会出现确认。涂抹只是覆盖在上面，下面的文字数据仍保留，因此机密信息请选择"将涂抹的页面转为图像后导出PDF（推荐）"——只有这些页面会变成图像，文字数据被删除。
- ［导出PNG］：所选页面或全部页面，96／150／300 dpi。
- 标注以图像形式烧录到 PDF 中（任何语言都能保留）。便签为注释。

## 13. 工作文件（.frontpdf）
- ［保存工作］(Ctrl+S) 保存为 .frontpdf。用［打开］或拖放打开后，可在页面结构、标注、印章、便签、水印均可编辑的状态下继续。也可交给同事，让其按便签指示修改。
- 注意：工作文件原样包含原 PDF（包括涂黑下的文字）。请勿交给组织外部人员，对外请发送导出的 PDF。
- 不包含印章簿和撤销历史。有未保存更改时标题带 *，关闭时会出现警告。

## 14. 显示与设置
- 缩放：整页／页宽／25–400%、Ctrl+滚轮、Ctrl+＋／－、Ctrl+0 显示整页。
- 缩略图：大小滑块、列数（自动／1–6）、Ctrl+滚轮。
- 皮肤：现代／深色／复古PC／Aqua／掌机。语言：日本語、English、简体中文、繁體中文、Português、Français、한국어。两者都会被记住。

## 15. 快捷键
- Ctrl+O 打开／Ctrl+S 保存工作／Ctrl+Z 撤销／Ctrl+Y 或 Ctrl+Shift+Z 重做／Ctrl+F 搜索／F3・Enter 下一个结果／Shift+Enter 上一个结果
- Delete 删除所选标注（焦点在缩略图时删除页面）／方向键微调（Shift 加大）／Esc 取消选择→选择工具
- PageUp・PageDown 翻页／Ctrl+A 全选缩略图（选字时全选本页文字）／Ctrl+C 复制所选文字／Ctrl+V 粘贴图片或文字
- Ctrl+滚轮・Ctrl+＋／－・Ctrl+0 缩放／Ctrl+Enter 确定便签输入

## 16. 分发与故障处理
- 公司邮件可能拦截 .html 附件 → 压缩为 ZIP，或使用共享文件夹／Teams。
- 从邮件或云端预览直接打开会受限（印章簿无法保存、无保存对话框、无法使用剪贴板等）→ 先保存到电脑再双击打开。
- 印章簿、皮肤、语言、便签作者名等保存在各电脑的浏览器中（localStorage，前缀 pdfkobo98.）。清除浏览器数据会丢失，建议备份印章簿。
- 不支持：直接改写 PDF 中已有文字、真正的涂黑删除（从 PDF 结构中删除；请改用页面图像化）、OCR、电子签名、创建表单。
