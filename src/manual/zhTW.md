# Front PDF 使用說明書（繁體中文）v1.1.1 (2026-11-24)

## 1. 概要
- Front PDF 是只要用瀏覽器（建議 Edge / Chrome）開啟一個 HTML 檔（約 4MB）即可使用的 PDF 編輯工具，無需安裝。
- 完全離線。檔案不會傳送到外部，所有處理都在本機瀏覽器內完成。
- 功能：PDF／圖片的合併、分割、排序、旋轉、刪除；在頁面上標註（筆、圖形、文字、便利貼、印章、表情符號、圖片）；塗黑／塗白；文字搜尋；框選複製文字（表格可直接貼到 Excel）；浮水印；統一 A4；2合1／4合1；匯出 PNG；工作檔案。
- 也可以新增空白頁，自由排版製作文件（類似文書處理軟體）。
- 附帶的「桌面」可將資料夾中的PDF、工作檔案和圖片以縮圖自由擺放，並進行合併、拆分、重新命名、移動和列印（見第16章）。

## 2. 畫面構成
- 標題列右側：圖片匯入（開啟 PNG/JPEG 時的排版：置於A4上／保持圖片尺寸）、外觀、語言（地球圖示）、?（說明）、ⓘ（版本與授權）。
- 工具列第1行：左上的檔案區（開啟／儲存PDF／儲存工作檔案／另存新檔／列印／PNG）、顯示（▦ 清單／✎ 編輯）、頁面（新增空白頁・左轉・右轉・複製・刪除頁面）、復原／重做。標題列的［桌面］切換到桌面（第16章）。
- 工具列第2列（僅編輯模式）：◀ 頁碼 ▶、縮放（－／選單／＋）、搜尋（輸入框、▲▼、結果數、全部醒目、全部塗黑）、全部（浮水印、清除標註）。
- 左側：縮圖（上方有「大小」滑桿與「欄數」），拖曳分隔線可調整寬度。
- 中左為工具箱（依功能分5組），中央為頁面檢視器，右側為屬性面板，底部為狀態列。

## 3. 模式
- 編輯模式（✎ 編輯）：左側縮圖，在右側頁面上直接標註。
- 網格模式（▦ 網格）：只顯示大縮圖，用於整理頁面。雙擊或按 Enter 進入該頁編輯。
- 雙頁顯示：點擊一張縮圖，再按住 Ctrl 點擊另一張，兩頁並排顯示且都可標註（正在操作的頁面有外框）。只點擊一頁即可恢復。

## 4. 開啟與合併
- 用［開啟］(Ctrl+O) 或拖放加入 PDF / PNG / JPEG / 工作檔案(.frontpdf)，數量不限。縮圖順序即合併順序。
- 圖片會轉換為單頁 PDF（依「圖片匯入」設定）。
- 無法開啟有密碼的 PDF。

## 5. 頁面操作
- 選取：點擊、Ctrl+點擊（追加）、Shift+點擊（範圍）、在縮圖區按 Ctrl+A（全選）。
- 排序：拖曳縮圖。
- 旋轉（↺↻）、複製、刪除頁面（Delete）對選取的頁面執行。新增空白頁會在目前頁面後插入 A4 空白頁。
- 復原 Ctrl+Z／重做 Ctrl+Y（頁面操作與標註共用歷程）。

## 6. 工具
- 選取：［選取］點擊選取標註、拖曳移動、拖四角縮放、方向鍵微調（Shift 為10倍）、Delete 刪除；從空白處拖曳可選取文字。［選字］只選取拖曳框內的文字。
- 繪製：［筆］、［毛筆］（慢＝粗、快＝細，繪圖板支援壓感，可切換為噴槍）、［螢光筆］、［橡皮擦］（筆跡只擦經過處，其他整體刪除，不會擦除原 PDF）。筆類按 Shift 畫45°直線，按 Ctrl 畫任意角度直線。
- 圖形：［矩形］［橢圓］［直線］［箭頭］［星形］［表格］（在右側面板設定列數、欄數，只有框線）。按 Shift 畫正方形／正圓／45°線。
- 填色·遮蓋：［醒目］（半透明黃色帶）、［塗白］、［塗黑］、［油漆桶］（點擊標註＝改色；點擊筆等圍出的內側＝填色）、［滴管］（擷取頁面顏色並設定到上一個工具或所選標註，繪製時可 Alt+點擊）。
- 插入：［文字］（點擊放置，在右側面板設定內容、大小、字型、顏色、背景）、［表情符號］（在面板中選擇後點擊放置，也可用 Win+.）、［便利貼］（紙條式，點擊後直接輸入，雙擊再次編輯）、［印章］（從右側印章簿選擇後點擊蓋章）、［圖片］（選擇檔案放置）。
- 右側面板按鈕：刪除／複製／移至最上層／移至最下層／套用到所有頁（在其他所有頁面相同位置複製）／設為預設／加入印章簿。

## 7. 印章簿
- 類型：勾選（✓）、花丸（表揚用）、方框、雙框、橢圓、圓章（1–3字直書）、日期章（上欄・日期・下欄）、方章（4字兩欄，從右起）、圖片（掃描印鑑）。
- 可編輯文字、顏色、大小、日期格式（2026.11.20 / ’26.11.20 / R8.11.20 等）；勾選「使用蓋章當天日期」則每次自動為當天日期。
- ［從圖片新增］可新增掃描的印鑑（白色自動變透明）。
- 自動儲存在瀏覽器中（每台電腦、每個瀏覽器各自儲存）。［匯出（備份）］產生 StampBook_Front_PDF.json，［匯入］讀取。

## 8. 便利貼
- 紙條式便利貼。顏色（黃、粉紅、淺藍、綠、橘、紫、白）、字級、文字顏色、粗體、作者名稱（會被記住）。
- 匯出 PDF 時成為「註解」：Acrobat 與 Edge 中依原樣顯示，接收者可移動或刪除，並會出現在註解清單中。開啟「燒錄到頁面」則成為內文的一部分。
- 2合1／4合1 匯出時不包含便利貼。

## 9. 文字選取・複製・搜尋
- ［選字］：只選取中心位於拖曳框內的文字，也可只選表格的某幾欄。
- 複製格式：表格（Tab 分隔，貼到 Excel 會分成儲存格）／文字（空格分隔）。Ctrl+C 複製，Ctrl+A 全選本頁。
- 搜尋：Ctrl+F → 輸入 → Enter（下一個）／Shift+Enter（上一個）。不區分全形半形與大小寫。［全部醒目］［全部塗黑］可一次處理。
- 掃描的 PDF 沒有文字資料，無法選取或搜尋（不支援 OCR）。

## 10. 浮水印
- ［浮水印］為所有頁面加入浮水印並選取。可在右側面板修改文字、大小、角度、顏色、濃度，或［刪除浮水印］。點擊頁面上的浮水印文字也可選取。

## 11. 貼上與拖放圖片
- 用剪取工具等複製的圖片按 Ctrl+V：滑鼠在頁面上時貼在該位置，否則貼在可見區域中央，大小與螢幕上看到的一致。滑鼠在縮圖區時作為新頁面加入。
- 將圖片檔拖放到頁面上＝貼在該位置；拖放到縮圖區＝新頁面。
- Ctrl+V 貼上文字時作為文字物件。

## 12. 儲存・列印
- ［儲存PDF］(Ctrl+S)：從桌面開啟的PDF會直接覆寫原檔案（舊版本保留在同一資料夾的「_削除予定」資料夾中，可用桌面的［復原］還原）。開啟工作檔案時，會在旁邊建立同名PDF。未使用桌面開啟時，與［另存新檔］相同。
- ［另存新檔］：選擇名稱和格式（PDF／工作檔案）儲存。預設選取目前開啟檔案的格式。PDF 可選擇：合併全部頁面／僅所選頁面／逐頁拆分／每N頁拆分／依範圍拆分（例 1-3, 4-6, 7）、統一為A4、裁切邊界（mm）、2合1・4合1、文件標題。
- 有塗黑・塗白時儲存前會提示確認。塗抹只是覆蓋在上面，下方文字資料仍會保留，機密資訊請選擇「將塗抹部分轉為影像儲存（推薦）」（只將該頁轉為影像，文字資料被刪除）。
- ［列印］(Ctrl+P)：連同標註・印章・便籤・浮水印一起列印。在 Edge 的列印畫面選擇印表機和份數。
- ［PNG］：將所選頁面／全部頁面以 96・150・300dpi 儲存為PNG。
- 標註會以影像形式寫入PDF（任何語言的文字都能原樣輸出）。便籤為註解。

## 13. 工作檔案 (.frontpdf)
- ［儲存工作檔案］儲存為 .frontpdf（開啟工作檔案時會覆寫）。用［開啟］、拖放或在桌面雙擊開啟，即可在頁面結構・標註・印章・便籤・浮水印都可編輯的狀態下繼續工作。也可交給同事依便籤指示修改。
- 注意：工作檔案中原樣包含原PDF（包括塗黑下的文字）。請勿交給外部人員，交出的應是用［儲存PDF］製作的PDF。
- 印章簿和復原記錄不包含在工作檔案中。有未儲存的變更時標題會帶 *，關閉時會出現警告。

## 14. 顯示與設定
- 縮放：整頁／頁寬／25–400%、Ctrl+滾輪、Ctrl+＋／－、Ctrl+0 顯示整頁。
- 縮圖：大小滑桿、欄數（自動／1–6）、Ctrl+滾輪。
- 外觀：現代／深色／復古PC／Aqua／掌機／毛茸茸。語言：日本語、English、简体中文、繁體中文、Português、Français、한국어。兩者都會被記住。
- 觸控操作（平板／觸控螢幕）：單指繪製、移動便利貼或圖形；使用選取工具時在空白處滑動可移動畫面。雙指捲動，張開／捏合可縮放。

## 15. 快速鍵
- Ctrl+O 開啟／Ctrl+S 儲存（從桌面開啟的PDF為儲存PDF，其他為儲存工作檔案）／Ctrl+P 列印／Ctrl+Z 復原／Ctrl+Y 或 Ctrl+Shift+Z 重做／Ctrl+F 搜尋／F3・Enter 下一個結果／Shift+Enter 上一個結果
- Delete 刪除選取的標註（焦點在縮圖時刪除頁面）／方向鍵微調（Shift 加大）／Esc 取消選取→選取工具
- PageUp・PageDown 換頁／Ctrl+A 全選縮圖（選字時全選本頁文字）／Ctrl+C 複製選取的文字／Ctrl+V 貼上圖片或文字
- Ctrl+滾輪・Ctrl+＋／－・Ctrl+0 縮放／Ctrl+Enter 確定便利貼輸入

## 16. 桌面 (Desk)
- 啟動後開啟桌面。用［選擇資料夾］選擇存放文件的最上層資料夾（也可選 Box Drive 資料夾），左側顯示資料夾清單，右側以縮圖排列 PDF・工作檔案（.frontpdf）・JPG・PNG。下次會自動開啟上次的資料夾（依瀏覽器規定可能需要點擊一次）。僅支援 Edge / Chrome。
- 縮圖可拖曳到任意位置。擺放位置儲存在資料夾內的「.frontpdf-desk」檔案中，與開啟同一資料夾的人共享。［整齊排列］依名稱重新排列，滑桿調整大小。邊框顏色：PDF＝紅，工作檔案＝藍，圖片＝綠。
- 開啟：雙擊或 Enter 在新視窗開啟編輯器；［編輯器］按鈕開啟空的編輯器。預覽：按空白鍵，或按下並放開 Ctrl+Shift（←→翻頁，↑↓切換文件，Enter 開啟，Esc 關閉）。
- 合併：將文件拖到另一個文件上（拖曳的在前，目標在後），或多選後右鍵［合併］。確認順序和名稱後建立。圖片會轉換為PDF頁面。包含工作檔案時結果為工作檔案，標註和便籤保留。
- 框選：從空白處拖曳，可一次選取框內的文件。按住 Ctrl（或 Shift）可追加到目前的選取，可多次框選。右鍵［合併］的順序：重疊的文件由上往下（拆分後的疊放保持原順序），不重疊的文件新的在前、舊的在後。
- 按頁拆分：將PDF逐頁拆分為單獨的PDF（同一資料夾／新資料夾）。工作檔案（.frontpdf）也可保留註記和便利貼，拆分為單頁工作檔案。合併和拆分時，「將原檔案移到_削除予定」預設勾選。
- 移動：拖到左側資料夾清單。從檔案總管拖入為匯入（複製）。Ctrl+C・Ctrl+V 複製，F2 重新命名，Ctrl+F 依檔名篩選，Ctrl+P 列印（PDF・圖片）。右鍵顯示選單。
- 刪除的檔案和覆寫前的舊版本會移到該資料夾內自動建立的「_削除予定」資料夾（不是 Windows 或 Mac 的垃圾桶）。不再需要時，右鍵點擊「_削除予定」資料夾→［清空］即可永久刪除（無法還原）。
- 復原 Ctrl+Z／重做 Ctrl+Y：移動・重新命名・刪除・合併・拆分・覆寫儲存等可多次復原。資料夾的變化（他人或 Box 同步）會自動反映。
- ［日誌］［複製日誌］：操作記錄。回報問題時請貼上。

## 17. 發布與疑難排解
- 公司郵件可能攔截 .html 附件 → 壓縮為 ZIP，或使用共用資料夾／Teams。
- 從郵件或雲端預覽直接開啟會受限（印章簿無法儲存、無儲存對話框、無法使用剪貼簿等）→ 先儲存到電腦再雙擊開啟。
- 印章簿、外觀、語言、便利貼作者名稱等儲存在各電腦的瀏覽器中（localStorage，前綴 pdfkobo98.）。清除瀏覽器資料會遺失，建議備份印章簿。
- 不支援：直接改寫 PDF 中既有文字、真正的塗黑刪除（從 PDF 結構中刪除；請改用頁面影像化）、OCR、電子簽章、建立表單。
