# Front PDF 사용 설명서 (한국어) v1.1.0 (2026-11-23)

## 1. 개요
- Front PDF는 브라우저(Edge / Chrome 권장)로 HTML 파일 하나(약 4MB)를 열기만 하면 작동하는 PDF 편집 도구입니다. 설치가 필요 없습니다.
- 완전 오프라인. 파일은 외부로 전송되지 않으며, 모든 처리는 PC의 브라우저 안에서만 이루어집니다.
- 기능: PDF·이미지의 병합, 분할, 순서 변경, 회전, 삭제; 페이지 주석(펜, 도형, 텍스트, 메모지, 도장, 이모지, 이미지); 검게/흰색 칠하기; 텍스트 검색; 범위 지정 텍스트 복사(표는 Excel에 그대로 붙여넣기 가능); 워터마크; A4 맞춤; 2-in-1/4-in-1; PNG 내보내기; 작업 파일.
- 빈 페이지를 추가해 레이아웃이 자유로운 문서 작성(워드프로세서처럼)도 가능합니다.
- 함께 들어 있는 "데스크"에서 폴더의 PDF・작업 파일・이미지를 썸네일로 자유롭게 늘어놓고 결합・분할・이름 변경・이동・인쇄할 수 있습니다(DocuWorks Desk처럼 사용. 16장).

## 2. 화면 구성
- 제목 표시줄 오른쪽: 이미지 가져오기(PNG/JPEG를 열 때의 배치: A4에 배치／이미지 크기 그대로), 스킨, 언어(지구 모양), ?(사용법), ⓘ(버전·라이선스).
- 도구 모음 1단: 왼쪽 위의 파일 영역(열기／PDF 저장／작업 파일 저장／다른 이름으로 저장／인쇄／PNG), 표시(▦ 목록／✎ 편집), 페이지(빈 페이지 추가・왼쪽 회전・오른쪽 회전・복제・페이지 삭제), 실행 취소／다시 실행. 제목 표시줄의 [데스크]로 데스크(16장)로 전환.
- 툴바 2단(편집 모드만): ◀ 페이지 번호 ▶, 배율(－／메뉴／＋), 검색(입력란, ▲▼, 건수, 모두 강조, 모두 검게), 전체(워터마크, 주석 모두 지우기).
- 왼쪽: 썸네일(위에 "크기" 슬라이더와 "열"). 경계를 드래그해 폭 변경.
- 도구 상자(기능별 5그룹), 가운데 페이지 뷰어, 오른쪽 속성 패널, 아래 상태 표시줄.

## 3. 모드
- 편집 모드(✎ 편집): 왼쪽 썸네일, 오른쪽 페이지에 직접 주석.
- 목록 모드(▦ 목록): 큰 썸네일만 나열해 페이지 정리. 더블클릭 또는 Enter로 그 페이지 편집.
- 2페이지 보기: 썸네일 하나를 클릭한 뒤 Ctrl을 누른 채 다른 썸네일을 클릭하면 두 페이지가 나란히 표시되고 둘 다 주석을 넣을 수 있습니다(조작 중인 페이지는 테두리 표시). 한 페이지만 클릭하면 돌아갑니다.

## 4. 열기·병합
- [열기](Ctrl+O) 또는 드래그 앤 드롭으로 PDF / PNG / JPEG / 작업 파일(.frontpdf)을 추가. 개수 제한 없음. 썸네일 순서가 병합 순서입니다.
- 이미지는 1페이지 PDF로 변환됩니다("이미지 가져오기" 설정에 따름).
- 암호가 걸린 PDF는 열 수 없습니다.

## 5. 페이지 조작
- 선택: 클릭, Ctrl+클릭(추가), Shift+클릭(범위), 썸네일 쪽에서 Ctrl+A(전체).
- 순서 변경: 썸네일을 드래그.
- 회전(↺↻)·복제·페이지 삭제(Delete)는 선택한 페이지에 적용. 빈 페이지는 현재 페이지 뒤에 A4 빈 페이지를 삽입.
- 실행 취소 Ctrl+Z／다시 실행 Ctrl+Y(페이지 조작과 주석 공통 이력).

## 6. 도구
- 선택: [선택] 주석을 클릭해 선택, 드래그로 이동, 모서리로 크기 조절, 방향키로 미세 조정(Shift는 10배), Delete로 삭제. 빈 곳에서 드래그하면 텍스트 선택. [텍스트 선택] 드래그한 테두리 안의 텍스트만 선택.
- 그리기: [펜], [붓](천천히=굵게, 빠르게=가늘게, 펜 태블릿은 필압, 에어브러시로 전환 가능), [형광펜], [지우개](펜 선은 지나간 곳만, 그 외는 통째로 삭제. 원본 PDF는 지워지지 않음). 펜 종류는 Shift로 45° 단위 직선, Ctrl로 자유 각도 직선.
- 도형: [사각형] [원] [선] [화살표] [별] [표](오른쪽 패널에서 행 수·열 수 지정, 테두리만). Shift로 정사각형／정원／45° 선.
- 칠하기·가리기: [강조](반투명 노란 띠), [흰색 칠], [검게 칠], [채우기](주석 클릭＝색 변경, 펜 등으로 둘러싼 안쪽 클릭＝채우기), [스포이트](페이지의 색을 가져와 직전 도구 또는 선택한 주석에 설정. 그리는 중 Alt+클릭도 가능).
- 넣기: [텍스트](클릭으로 배치, 오른쪽 패널에서 내용·크기·글꼴·색·배경), [이모지](패널에서 골라 클릭으로 배치, Win+.도 가능), [메모지](종이 메모 형태. 클릭 후 바로 입력, 더블클릭으로 다시 편집), [도장](오른쪽 도장 모음에서 골라 클릭), [이미지](파일을 골라 배치).
- 오른쪽 패널 버튼: 삭제／복제／맨 앞으로／맨 뒤로／모든 페이지에(다른 모든 페이지의 같은 위치에 복제)／기본값으로／도장 모음에 등록.

## 7. 도장 모음
- 종류: 체크(✓), 꽃동그라미(칭찬 도장), 사각 테두리, 이중 테두리, 타원, 원형 인(1~3자 세로쓰기), 날짜 도장(윗단·날짜·아랫단), 사각 인(4자를 2열로, 오른쪽부터), 이미지(스캔한 인영).
- 텍스트·색·크기·날짜 형식(2026.11.20 / ’26.11.20 / R8.11.20 등)을 편집 가능. "찍은 날 날짜 사용"이면 매번 그날 날짜가 들어갑니다.
- [이미지로 등록]으로 스캔한 인영을 등록(흰색은 자동으로 투명).
- 브라우저에 자동 저장(PC·브라우저별). [내보내기 (백업)]로 StampBook_Front_PDF.json, [불러오기]로 가져오기.

## 8. 메모지
- DocuWorks의 메모지 같은 종이 메모 형태. 색(노랑, 분홍, 하늘색, 초록, 주황, 보라, 흰색), 글자 크기·색, 굵게, 작성자 이름(기억됨).
- PDF로 내보내면 "주석"이 됩니다: Acrobat과 Edge에서 그대로 보이고, 받는 사람이 이동·삭제할 수 있으며 주석 목록에도 나옵니다. "페이지에 고정"을 켜면 본문의 일부가 됩니다.
- 2-in-1/4-in-1 내보내기에는 메모지가 포함되지 않습니다.

## 9. 텍스트 선택·복사·검색
- [텍스트 선택]: 글자 중심이 드래그한 테두리 안에 있는 글자만 선택. 표의 일부 열만 고를 수도 있습니다.
- 복사 형식: 표(탭 구분, Excel에 붙이면 셀로 나뉨)／문장(공백 구분). Ctrl+C로 복사, Ctrl+A로 페이지 전체.
- 검색: Ctrl+F → 입력 → Enter(다음)／Shift+Enter(이전). 전각·반각과 대소문자를 구분하지 않음. [모두 강조] [모두 검게]로 한꺼번에 처리.
- 스캔 PDF는 텍스트 데이터가 없어 선택·검색할 수 없습니다(OCR 미지원).

## 10. 워터마크
- [워터마크]로 모든 페이지에 워터마크를 넣고 선택 상태가 됩니다. 오른쪽 패널에서 텍스트·크기·각도·색·진하기 변경 또는 [워터마크 삭제]. 페이지의 워터마크 글자를 클릭해도 선택됩니다.

## 11. 이미지 붙여넣기·드롭
- 캡처 도구 등으로 복사한 이미지를 Ctrl+V: 마우스가 페이지 위에 있으면 그 위치, 아니면 보이는 영역 중앙에, 화면에서 본 크기로 붙습니다. 마우스가 썸네일 쪽이면 새 페이지로 추가.
- 이미지 파일을 페이지에 드롭＝그 위치에 배치, 썸네일 쪽에 드롭＝새 페이지.
- 텍스트를 Ctrl+V하면 텍스트 객체로 붙습니다.

## 12. 저장・인쇄
- [PDF 저장](Ctrl+S): 데스크에서 연 PDF는 원본 파일을 그대로 덮어씁니다(이전 버전은 같은 폴더의 '_削除予定' 폴더에 남고, 데스크의 [실행 취소]로 되돌릴 수 있음). 작업 파일을 열고 있을 때는 같은 이름의 PDF를 옆에 만듭니다. 데스크를 쓰지 않고 열었을 때는 [다른 이름으로 저장]과 같습니다.
- [다른 이름으로 저장]: 이름과 형식(PDF／작업 파일)을 골라 저장. 열려 있는 파일의 형식이 먼저 선택됩니다. PDF는 전체 페이지 결합／선택 페이지만／1페이지씩 분할／N페이지마다 분할／범위로 분할(예 1-3, 4-6, 7), A4 맞춤, 여백 자르기(mm), 2in1・4in1, 문서 제목을 고를 수 있습니다.
- 검게 칠하기・흰색 칠하기가 있으면 저장 전에 확인이 나옵니다. 칠한 부분은 위에 덮여 있을 뿐이라 아래 텍스트 데이터가 남으므로, 기밀 정보라면 "칠한 부분을 이미지로 저장(권장)"을 선택하세요(그 페이지만 이미지화되어 텍스트 데이터가 지워짐).
- [인쇄](Ctrl+P): 주석・도장・메모지・워터마크를 포함해 인쇄. Edge의 인쇄 화면에서 프린터와 부수를 고릅니다.
- [PNG]: 선택 페이지／전체 페이지를 96・150・300dpi PNG로.
- 주석은 이미지로 PDF에 새겨집니다(어떤 언어의 문자도 그대로 출력). 메모지는 PDF 주석이 됩니다.

## 13. 작업 파일(.frontpdf)
- [작업 파일 저장]으로 .frontpdf에 저장(작업 파일을 열고 있으면 덮어씀). [열기], 드롭, 데스크에서 더블클릭으로 열면 페이지 구성・주석・도장・메모지・워터마크를 편집 가능한 상태로 이어서 작업할 수 있습니다. 동료에게 건네 메모지 지시대로 수정해 달라고 하는 운용도 가능합니다.
- 주의: 작업 파일에는 원본 PDF(검게 칠한 아래의 텍스트도)가 그대로 들어 있습니다. 외부에 건네지 말고, 건넬 때는 [PDF 저장]으로 만든 PDF를 사용하세요.
- 도장 모음과 실행 취소 기록은 작업 파일에 포함되지 않습니다. 저장하지 않은 변경이 있으면 제목에 *가 붙고, 닫을 때 경고가 나옵니다.

## 14. 표시·설정
- 배율: 페이지 전체／페이지 너비／25~400%, Ctrl+휠, Ctrl+＋／－, Ctrl+0으로 전체 표시.
- 썸네일: 크기 슬라이더, 열(자동／1~6), Ctrl+휠.
- 스킨: 모던／다크／레트로 PC／아쿠아／게임기／몽글몽글. 언어: 日本語, English, 简体中文, 繁體中文, Português, Français, 한국어. 둘 다 기억됩니다.

## 15. 단축키
- Ctrl+O 열기／Ctrl+S 저장(데스크에서 연 PDF는 PDF 저장, 그 외에는 작업 파일 저장)／Ctrl+P 인쇄／Ctrl+Z 실행 취소／Ctrl+Y 또는 Ctrl+Shift+Z 다시 실행／Ctrl+F 검색／F3・Enter 다음 결과／Shift+Enter 이전 결과
- Delete 선택한 주석 삭제(썸네일 쪽이면 페이지)／방향키 미세 조정(Shift로 크게)／Esc 선택 해제→선택 도구
- PageUp・PageDown 페이지 이동／Ctrl+A 썸네일 전체 선택(텍스트 선택 중에는 페이지 전체 텍스트)／Ctrl+C 선택한 텍스트 복사／Ctrl+V 이미지·텍스트 붙여넣기
- Ctrl+휠・Ctrl+＋／－・Ctrl+0 배율／Ctrl+Enter 메모지 입력 확정

## 16. 데스크 (Desk)
- 시작하면 데스크가 열립니다. [폴더 선택]으로 문서가 있는 최상위 폴더(Box Drive 폴더도 가능)를 고르면 왼쪽에 폴더 목록, 오른쪽에 PDF・작업 파일(.frontpdf)・JPG・PNG가 썸네일로 늘어섭니다. 다음부터는 지난번 폴더를 자동으로 엽니다(브라우저 규칙상 한 번 클릭이 필요할 수 있음). Edge / Chrome만 지원.
- 썸네일은 드래그로 원하는 곳에 둘 수 있습니다. 배치는 폴더 안의 '.frontpdf-desk' 파일에 저장되어 같은 폴더를 여는 사람과 공유됩니다. [정렬]로 이름순 재정렬, 슬라이더로 크기 변경. 테두리 색: PDF＝빨강, 작업 파일＝파랑, 이미지＝초록.
- 열기: 더블클릭 또는 Enter로 새 창 편집기가 열립니다. [편집기] 버튼은 빈 편집기를 엽니다. 미리 보기: 스페이스, 또는 Ctrl+Shift를 눌렀다 떼기(←→ 페이지, ↑↓ 문서, Enter 열기, Esc 닫기).
- 결합: 문서를 다른 문서 위에 겹치거나(겹친 문서가 앞, 대상이 뒤), 여러 개 선택 후 오른쪽 클릭 [결합]. 순서와 이름을 확인한 뒤 만듭니다. 이미지는 PDF 페이지로 변환됩니다. 작업 파일이 포함되면 결과는 작업 파일이 되고 주석과 메모지가 그대로 남습니다.
- 페이지별로 나누기: PDF를 1페이지씩 별도 PDF로 나눕니다(같은 폴더／새 폴더).
- 이동: 왼쪽 폴더 목록으로 드래그. 탐색기에서 드롭하면 가져오기(복사). Ctrl+C・Ctrl+V 복제, F2 이름 변경, Ctrl+F 파일 이름 필터, Ctrl+P 인쇄(PDF・이미지). 오른쪽 클릭으로 메뉴.
- 삭제한 파일과 덮어쓰기 전의 이전 버전은 그 폴더 안에 자동으로 만드는 '_削除予定' 폴더로 옮깁니다(Windows나 Mac의 휴지통이 아님). 필요 없어지면 '_削除予定' 폴더를 오른쪽 클릭→[비우기]로 완전히 삭제(되돌릴 수 없음).

## 17. 배포·문제 해결
- 회사 메일에서 .html 첨부가 차단될 수 있음 → ZIP으로 묶거나 공유 폴더／Teams로 배포.
- 메일이나 클라우드 미리보기에서 바로 열면 제한이 걸림(도장 모음이 기억되지 않음, 저장 대화상자가 안 나옴, 클립보드 사용 불가 등) → PC에 저장한 뒤 더블클릭으로 열기.
- 도장 모음·스킨·언어·메모지 작성자 이름 등은 각 PC의 브라우저(localStorage, 접두사 pdfkobo98.)에 저장. 브라우저 데이터를 지우면 사라지므로 도장 모음은 백업 권장.
- 미지원: PDF의 기존 텍스트 직접 수정, 진짜 먹칠(PDF 구조에서 삭제. 대신 페이지 이미지화 사용), OCR, 전자 서명, 양식 작성.
