# Front PDF 操作説明書（日本語） v1.0.2 (2026-11-22)


## 1. 概要 (Overview)
- Front PDF は、ブラウザ（Edge / Chrome 推奨）で開くだけで動く PDF 編集ツール。インストール不要、1つの HTML ファイル（約3.7MB）。
- 完全オフライン。ファイルは外部に送信されず、PC のブラウザ内だけで処理される。
- できること：PDF/画像の結合・分割・並べ替え・回転・削除、ページへの書き込み（ペン・図形・文字・付箋・ハンコ・絵文字・画像）、黒塗り/白塗り、文字検索、範囲指定の文字コピー（表は Excel にそのまま貼れる）、透かし、A4 揃え、2in1/4in1、PNG 書き出し、作業ファイル保存。
- 白紙ページを追加して、レイアウト自由な文書作成（Word 的な使い方）もできる。

## 2. 画面構成 (Screen layout)
- タイトルバー右：画像取込（PNG/JPEG を開いたときの配置：A4に配置／画像サイズのまま）、スキン、言語（地球マーク）、？（使い方）。
- ツールバー1段目：ファイル（開く／作業を保存）、表示（▦ 一覧／✎ 編集）、ページ（白紙追加・左回転・右回転・複製・ページ削除）、元に戻す／やり直し、右端に書き出し（PNG書き出し／PDF書き出し）。
- ツールバー2段目（編集モードのみ）：◀ ページ番号 ▶、倍率（－／メニュー／＋）、検索（入力欄・▲▼・件数・全てマーカー・全て黒塗り）、全体（透かし・書き込み全消去）。
- 左：サムネイル（上部に「大きさ」スライダーと「列」）。境目ドラッグで幅変更。
- 中央左：ツールボックス（機能別5グループ）。中央：ページビューワー。右：プロパティパネル（選択中の書き込みやツールの設定）。下：ステータスバー（ページ数／選択数、案内メッセージ）。

## 3. モード (Modes)
- 編集モード（✎ 編集）：左にサムネイル、右のページに直接書き込む。
- 一覧モード（▦ 一覧）：サムネイルだけを大きく並べてページ整理。ダブルクリックまたは Enter でそのページの編集へ。
- 2ページ表示：サムネイルで1枚クリック → Ctrl+クリックでもう1枚 → 2ページが並んで表示され、両方に書き込める（操作中のページは枠付き）。1枚だけクリックすると戻る。

## 4. ファイルを開く・結合 (Open & merge)
- ［開く］(Ctrl+O) またはドラッグ＆ドロップで PDF / PNG / JPEG / 作業ファイル(.frontpdf) を追加。何個でも可。サムネイルの順番がそのまま結合順。
- 画像ファイルは1ページの PDF に変換して追加（設定「画像取込」に従う）。
- パスワード付き PDF は開けない。

## 5. ページ操作 (Page operations)
- 選択：クリック、Ctrl+クリック（追加）、Shift+クリック（範囲）、サムネイル欄で Ctrl+A（全選択）。
- 並べ替え：サムネイルをドラッグ。
- 回転（↺↻）・複製・ページ削除（Delete）は選択ページに対して実行。白紙追加は表示中ページの後ろに A4 白紙を挿入。
- 元に戻す Ctrl+Z ／ やり直し Ctrl+Y（ページ操作と書き込みの共通履歴）。

## 6. ツール一覧 (Tools in the toolbox)
- 選択：［選択］書き込みのクリック選択・移動・四隅で拡大縮小・矢印キーで微調整（Shift で10倍）・Delete で削除。何もない所からドラッグすると文字選択になる。／［文字選択］ドラッグで囲んだ枠内の文字だけを選択。
- 描く：［ペン］［ブラシ］（筆ペン：遅い＝太い／速い＝細い、ペンタブは筆圧、種類でエアブラシも）［蛍光ペン］［消しゴム］（ペン類はなぞった所だけ、その他は丸ごと消去。元PDFは消えない）。ペン類は Shift で45°刻みの直線、Ctrl で自由角度の直線。
- 図形：［四角］［丸］［線］［矢印］［星］［表］（表は右パネルで行数・列数を指定、枠線のみ）。Shift で正方形・正円・45°線。
- 塗る・隠す：［マーカー］（半透明の黄色い帯）［白塗り］［黒塗り］［バケツ］（書き込みをクリック＝色変更、ペン等で囲んだ内側をクリック＝塗りつぶし）［スポイト］（ページ上の色を拾い、直前のツールまたは選択中の書き込みにセット。描画中は Alt+クリックでも可）。
- 入れる：［文字］（クリックで配置、右パネルで内容・大きさ・書体・色・背景）［絵文字］（パネルから選んでクリックで配置、Win+. でも入力可）［付箋］（貼り紙型。クリックで貼ってそのまま入力、ダブルクリックで再編集）［ハンコ］（右のハンコ帳から選んでクリック）［画像］（ファイルを選んで配置）。
- 右パネルのボタン：削除／複製／最前面／最背面／全ページへ（他の全ページの同じ位置に複製）／既定にする（次回の初期設定）／ハンコ帳に登録。

## 7. ハンコ帳 (Stamp book)
- 種類：チェック（✓）、花まる、角枠、二重枠、小判型、丸印（1〜3字は縦書き）、日付印（上段・日付・下段）、角印（4字で2列・右から）、画像（印影）。
- 文字・色・大きさ・日付形式（2026.11.20 / ’26.11.20 / R8.11.20 など）を編集でき、「押した日の日付にする」で毎回当日の日付。
- ［画像から登録］でスキャンした印影を登録（白は自動で透明）。
- 内容はブラウザに自動保存（PC・ブラウザごと）。［書出（バックアップ）］で StampBook_Front_PDF.json、［読込］で取り込み。

## 8. 付箋 (Sticky notes)
- DocuWorks の付箋のような貼り紙型。色（黄・ピンク・水色・緑・オレンジ・紫・白）、文字の大きさ・色・太字、作成者名（記憶）。
- PDF 書き出し時は「注釈」として入る：Acrobat や Edge で見たまま表示され、受け取った人が移動・削除でき、コメント一覧にも出る。「ページに焼き込む」をオンにすると本文の一部になる。
- 2in1/4in1 書き出しでは注釈の付箋は含まれない。

## 9. 文字の選択・コピー・検索 (Text)
- ［文字選択］でドラッグした枠の中の文字だけを選択（文字の中心が枠内のもの）。表の一部の列だけも可。
- コピー形式：表（タブ区切り＝Excel に貼るとセルに分かれる）／文章（スペース区切り）。Ctrl+C でコピー、Ctrl+A でページ全体。
- 検索：Ctrl+F → 入力 → Enter（次）／Shift+Enter（前）。全角半角・大文字小文字は区別しない。［全てマーカー］［全て黒塗り］で一括処理。
- スキャン画像の PDF は文字データが無いので選択・検索できない（OCR 非対応）。

## 10. 透かし (Watermark)
- ［透かし］で全ページ共通の透かしを追加して選択状態に。右パネルで文字・大きさ・角度・色・濃さ、［透かしを削除］。ページ上の透かし文字をクリックしても選べる。

## 11. 画像の貼り付け (Paste / drop images)
- Snipping Tool などでコピーした画像を Ctrl+V：マウスがページ上ならその位置、それ以外は表示中の中央に、画面で見た大きさで貼る。マウスがサムネイル側なら新しいページとして追加。
- 画像ファイルをページ上にドロップ＝その位置に貼る／サムネイル側にドロップ＝新しいページ。
- 文字列を Ctrl+V するとテキストとして貼り付け。

## 12. 書き出し (Export)
- ［PDF書き出し］：全ページを結合／選択ページだけ／1ページずつ分割／Nページごとに分割／範囲で分割（例 1-3, 4-6, 7）。オプション：A4 に揃える、余白トリミング（mm）、2in1・4in1、文書タイトル。
- 黒塗り・白塗りがあると確認が出る。塗りは上に重ねているだけで下の文字データが残るため、機密情報なら「塗ったページを画像化して PDF 出力（推奨）」を選ぶ（そのページだけ画像化され文字データが消える）。
- ［PNG書き出し］：選択ページ／全ページを 96・150・300dpi で PNG に。
- 書き込みは画像として PDF に焼き込まれる（どの言語の文字もそのまま出る）。付箋は注釈。

## 13. 作業ファイル (Work file .frontpdf)
- ［作業を保存］(Ctrl+S) で .frontpdf に保存。［開く］またはドロップで開くと、ページ構成・書き込み・ハンコ・付箋・透かしを編集可能な状態で再開できる。同僚に渡して付箋の指示に従って修正してもらう運用も可能。
- 注意：作業ファイルには元の PDF（黒塗りの下の文字も）がそのまま入る。社外には渡さず、渡すのは PDF 書き出しした PDF。
- ハンコ帳と元に戻す履歴は作業ファイルに含まれない。未保存の変更があるとタイトルに * が付き、閉じる時に警告が出る。

## 14. 表示・設定 (View & settings)
- 倍率：ページ全体／ページ幅／25〜400%、Ctrl+ホイール、Ctrl+＋／－、Ctrl+0 で全体表示。
- サムネイル：大きさスライダー・列（自動/1〜6）、Ctrl+ホイール。
- スキン：モダン／ダーク／レトロPC／アクア／ゲーム機。言語：日本語・English・简体中文・繁體中文・Português・Français・한국어。どちらも記憶される。

## 15. キーボードショートカット (Shortcuts)
- Ctrl+O 開く / Ctrl+S 作業を保存 / Ctrl+Z 元に戻す / Ctrl+Y・Ctrl+Shift+Z やり直し / Ctrl+F 検索 / F3・Enter 次の検索結果 / Shift+Enter 前の結果
- Delete 選択した書き込み（サムネイル側ではページ）を削除 / 矢印キー 微調整（Shift で大きく） / Esc 選択解除→選択ツールへ
- PageUp・PageDown ページ移動 / Ctrl+A サムネイル全選択（文字選択中はページの全文字） / Ctrl+C 選択した文字をコピー / Ctrl+V 画像・文字を貼り付け
- Ctrl+ホイール・Ctrl+＋／－・Ctrl+0 倍率 / Ctrl+Enter 付箋の入力確定

## 16. 配布・トラブル対応 (Distribution & troubleshooting)
- 会社のメールでは .html 添付がブロックされることがある → ZIP にするか共有フォルダ／Teams で配布。
- メールのプレビューやクラウドのプレビュー画面から直接開くと制限がかかる（ハンコ帳が記憶されない、保存ダイアログが出ない、クリップボードが使えない等）→ PC に保存してからダブルクリックで開く。
- ハンコ帳・スキン・言語・付箋の作成者名などは各 PC のブラウザ（localStorage、キー接頭辞 pdfkobo98.）に保存。ブラウザのデータ消去で消えるので、ハンコ帳はバックアップ推奨。
- 既存 PDF の文字を直接書き換える機能、本物の墨消し（PDF 構造からの削除。代わりにページ画像化を使う）、OCR、電子署名、フォーム作成は非対応。
